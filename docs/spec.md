# Спецификация: Развитие «На двоих» (Планы, Лента «Куда сходить», Быстрое добавление, i18n, Фидбек и B2B Аналитика)

## 1. Scope (Границы задач)

### В рамках релиза (In Scope):
1. **Проверка и гарантия стабильности синхронизации:**
   - Внедрение `render.yaml` для гарантированного автодеплоя коммитов из GitHub на Render.
   - Проверка SSE delta-стрима и автослияния без задержек и повторных вибраций.
2. **Кнопка обратной связи (Feedback & Contact):**
   - Модальное окно обратной связи в приложении (предложение идеи, отзыв, сообщение об ошибке).
   - Отправка на бэкенд `/api/feedback` + прямой переход в Telegram к разработчику с автокопированием диагностического лога самописца.
3. **Умное и быстрое добавление (Quick Add & Smart Paste):**
   - Компактный диалог по нажатию «+» вместо длинного списка полей.
   - Поле умной вставки: при вставке ссылки (Telegram, Instagram, 2GIS, Яндекс Карты, Restoclub, Афиша) автопарсинг через `/api/link-preview` (название, фото, описание).
   - Сохранение в 1 клик; аккордеон «Детали» (дата, бюджет) открывается только по желанию.
4. **Лента мест и идей «Куда сходить» (Couples Discovery Feed):**
   - Интерактивная витрина романтических мест и событий (рестораны, выставки, концерты, спа, кино).
   - Фильтр по городу (Санкт-Петербург, Москва, Все города).
   - Кнопка «+ В наши планы» у каждой карточки — мгновенно переносит идею в личный список пары.
5. **Английский язык (English / i18n) и Usability:**
   - Легковесный модуль локализации (RU / EN).
   - Переключатель языка в настройках приложения.
   - Полная поддержка всех экранов (Идеи, Календарь, Быт, Цель, Лента, Синхронизация).
6. **Облачный бэкап и сохранность данных (Cloud Backup):**
   - Мгновенный экспорт и импорт полной резервной копии JSON.
   - Интеграция сохранения копии в облако для 100% защиты от потери данных.
7. **Анонимная B2B-аналитика трендов:**
   - Серверный агрегатор популярных заведений и ссылок по городам (без персональных данных).
   - Эндпоинт статистики популярности мест (для партнерских интеграций и акций в ленте).

### Вне текущего спринта (Out of Scope):
- Интеграция эквайринга/онлайн-оплаты внутри Mini App (бронирование идет по ссылкам партнеров).
- Видеохостинг пользовательских видеофайлов (используются внешние ссылки и оптимизированные фото).

## 2. Архитектура и структуры данных

### 2.1. Feedback Endpoint (`/api/feedback`)
```typescript
interface FeedbackPayload {
  userId: string;
  type: "idea" | "bug" | "praise" | "other";
  message: string;
  contact?: string;
  telemetryLogs?: string;
}
```

### 2.2. Discovery Feed Item («Куда сходить»)
```typescript
interface DiscoveryPlace {
  id: string;
  city: "spb" | "msk" | "all";
  category: "food" | "culture" | "events" | "relax";
  title: string;
  tagline: string;
  description: string;
  imageUrl: string;
  linkUrl: string;
  badge?: string; // "Акция для пар", "Трендовое место", "Скидка 15%"
  avgCheck?: string;
}
```

### 2.3. B2B Trends Aggregator
```typescript
interface PlaceTrendMetric {
  placeName: string;
  city: string;
  domain: string;
  saveCount: number;
  lastAddedAt: string;
}
```

## 3. План реализации по шагам

1. **Шаг 1: Деплой и фиксация базовой синхронизации (Render Blueprint):**
   - Зафиксировать `render.yaml`, запушить в `main`, убедиться в автоматической сборке и доступности `/api/telemetry`.
2. **Шаг 2: Умное быстрое добавление (Quick Add & Smart Paste):**
   - Компактный интерфейс создания заметок в 1 клик с парсингом ссылок на лету.
3. **Шаг 3: Раздел «Куда сходить» (Лента свиданий):**
   - Каталог проверенных мест для свиданий с кнопкой добавления в планы пары.
4. **Шаг 4: Кнопка связи с разработчиком и форма фидбека:**
   - Модалка обратной связи с автоотправкой и возможностью прикрепить самописец.
5. **Шаг 5: Двуязычность (RU / EN):**
   - Словарь фраз, автопереключение и сохранение языка.
6. **Шаг 6: Облачный бэкап и B2B агрегатор трендов:**
   - Экспорт/импорт бэкапов и анонимная аналитика популярных локаций.
